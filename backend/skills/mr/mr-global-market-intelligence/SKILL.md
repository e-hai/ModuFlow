# 全球赛道摸底与截胡实战技能 (mr-global-market-intelligence)

## 核心执行步骤
1. **自下而上 SOM 精算**：调用专属 MCP 工具 `calculate_bottom_up_som` 或运行 `[som_calc.py](./scripts/som_calc.py)` 测算首年现实可获盘子。
2. **扒全球流量钩子与 ASO 词**：拆解头部爆款在 TikTok/Reels/Shorts/Reddit 上前 3 秒跨文化视觉钩子。
3. **深挖 1-2 星差评软肋**：调用 `analyze_competitor_weakness_matrix` 建立 Top 5 竞品差评与截胡刀法矩阵。
